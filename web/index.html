Draftling, a writerdeck

Draftling is an open-source software project that implements a Writerdeck, or a Word Processor: a small device dedicated to writing texts on the go. You take one of the supported devices, flash the firmware, attach a Bluetototh Low Energy keyboard, and you're ready to write. You can configure Wi-Fi access and a Git repository where your text files would be uploaded and synchronized, if you edit them from multiple places.

The editor supports Markdown, Fountain screenplay, or plain text files.

Setting up a device

The following devices are ready to use out of the box. See also the project page for a variety of supported DIY boards.
  • Xteink X4 Pro (unlocked devices only!)
  • Xteink X4 Classic (unlocked devices only!)
  • Seeed reTerminal Sticky
  • M5Stack PaperMono / PaperMono-Lite
  • LilyGO T5 E-Paper S3 Pro / Pro Lite
  • Waveshare ESP32-S3-Touch-LCD-3.49
  • Seeed Studio reTerminal E1001
  • M5Stack PaperS3 (discontinued)

Once you have the device, connect it to your computer via USB cable and open the web flasher in a browser. Allow the USB serial connection, select the right hardware type and flash the firmware.

You will need a Bluetooth Low Energy (BLE) keyboard to start working with the editor. There are hundreds of models on the market, so choose the one that fits you best. If BLE pairing takes too long, press the Boot button on your Draftling device for 2 seconds, and it will forghet all previous pairings and search for a new keyboard.

Also, insert a formatted MicroSD card in the device. It doesn't need to be any big size, as we only work with text.

Preferences and Settings

By pressing the F1 key, you get access to a number of settings, such as font size, orientation, and preferred keyboard layout(s). The append-only mode, if enabled, prevents you from erasing your text accidentally. Also, the Wi-Fi connection dialog lets you establish the Internet connnection for file uploads.

You can enable USB access to your SD card in F1 menu. This way, you don't need to take it from the device and look for an SD card reader.

Draftling uses Git for file synchronization. If you have an account at GitHub or Codeberg or some other public Git hosting, you need to create a read-write token for your repository and place it in git.cfg on the SD card.

As an alternative to Github and others, I built Draftbox, an easy to use Git hosting service tailored for writers. You create a repository, then create an access token, and Draftbox generates a one-time password that you enter in the Draftling F1 menu, and the repository is automatically attached to your device. You can start writing and uploading your files right away.

Writing

You press Ctrl+N to create a new file, Ctrl+S to save it (Draftling will prompt for a file name), and the rest is pretty easy and standard. F10 shows a help window with all the shortcuts.

Once you have a piece of text ready, press Ctrl+W to connect Draftling to internet, then Ctrl+G will synchronize the files with the Git server.

You can review your writing from your computer, either by browsing the Git repository in a browser, or by downloading the files locally by using one of Git clients. Commit and push your edits to Git, and Draftling will pick them up in next synchronization.
