# Typing guide: Chinese pack

Layouts: US and ZH (Simplified Chinese, pinyin input). Use a
US-English keyboard. ZH is active from the start; **Ctrl+L** or
**Win+Space** switches between US and ZH.

## How it works

Type pinyin without tones. The letters appear in the text and the
candidates in the status bar; syllables are split automatically.

| Key | Action |
|-----|--------|
| Space | accept the selected candidate |
| 1 .. 9 | accept a candidate of the page |
| Left / Right | select the previous / next candidate |
| Up / Down, PageUp / PageDown, `-` / `=` | previous / next page |
| Enter | keep the letters as typed |
| Esc | drop the letters |
| Backspace | delete the last letter |
| `'` | force a syllable break (`xi'an`) |
| `v` | u with umlaut (`lv`, `nv`) |

The list starts with words for all typed syllables, then for fewer
syllables, down to single characters. Accepting a shorter word leaves
the rest of the letters for the next pick.

## Examples

| Keys | Result |
|------|--------|
| `nihao` Space | ni hao (hello) |
| `zhongguo` Space | Zhongguo (China) |
| `xi'an` Space | Xi'an |
| `lvse` Space | lyuse (green) |

## Tips

- Outside a composition, `,` `.` `?` `!` `:` `;` and `\` type
  full-width Chinese punctuation.
- The search, file-name and WiFi fields take plain letters.
