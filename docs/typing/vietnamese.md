# Typing guide: Vietnamese pack

Layouts: US and VI (Vietnamese, Telex input). Use a US-English
keyboard. VI is active from the start; **Ctrl+L** or **Win+Space**
switches between US and VI.

## Telex in one minute

Type the letters of the word, then the marks. The word is fixed up as
you type, and a mark can be added any time while the cursor is at the
end of the word.

| Keys | Result |
|------|--------|
| `aa` `ee` `oo` | a, e, o with circumflex |
| `aw` | a with breve |
| `ow` `uw` | o, u with horn (`uow` gives both horns) |
| `w` alone | u with horn |
| `dd` | d with stroke |
| `s` `f` `r` `x` `j` | tone: acute, grave, hook above, tilde, dot below |
| `z` | remove the tone |
| a mark key twice | the letter itself (`ass` -> as) |

## Examples

| Keys | Word |
|------|------|
| `Vieejt Nam` | Viet Nam (e with circumflex and dot below) |
| `tieengs Vieejt` | tieng Viet |
| `dduwowcj` | duoc (d with stroke, both horns, dot below) |
| `nguwowif` | nguoi (both horns, grave) |

## Tips

- Tones go on the traditional position: `hoaf` puts the grave on the o.
- Marks are applied only to words that look like Vietnamese syllables,
  so most English words come through unchanged. Still, switch to US
  for English text: short words like `is` are valid Vietnamese.
- The search, file-name and WiFi fields take plain letters.
